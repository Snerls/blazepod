# Building the iOS app on your MacBook

The web app you've been testing in Bluefy is wrapped as a native iOS app via
[Capacitor](https://capacitorjs.com/). Native iOS apps use **CoreBluetooth**
directly, which exposes the manufacturer-specific advertisement data that the
BlazePod auth handshake requires — the one thing iOS Web Bluetooth strips.

You only do this setup once. After that, every code change is `git pull` +
two short commands.

## One-time prerequisites on your MacBook

1. **Install Xcode** from the Mac App Store (free, ~7 GB download).
   First launch will ask to install command-line tools — accept.
2. **Install Node.js**: `brew install node`  (or grab the LTS installer from
   [nodejs.org](https://nodejs.org/)).
3. **Sign in to Xcode with your Apple ID**: Xcode → Settings → Accounts → +.
   Just your normal Apple ID, free, no developer membership needed.

## First build

```bash
git clone https://github.com/Snerls/blazepod.git
cd blazepod
npm install
npm run ios:open
```

`ios:open` does three things in sequence:
1. `vite build`          — bundles the web app into `dist/`
2. `npx cap sync ios`    — copies `dist/` into the Xcode project
3. `npx cap open ios`    — opens Xcode

In Xcode:

1. **Set the signing team:** In the left panel click the **App** project (top
   blue icon) → **Signing & Capabilities** tab → **Team:** pick your personal
   Apple ID from the dropdown. Bundle Identifier `dk.snerls.blazepod` is fine
   (or change to `dk.<your-name>.blazepod`).
2. **Plug your iPhone into the Mac** with a Lightning/USB-C cable.
   On the iPhone tap **Trust** when it asks.
3. **Pick your iPhone as the run target:** in Xcode's top toolbar, the
   device dropdown (next to the ▶ button). Pick your iPhone (not "Any iOS
   Device" or a simulator).
4. **Click the ▶ Run button.**

Xcode builds, signs, installs the app on your iPhone, and launches it. First
time, the iPhone will say "Untrusted Developer" — go to:
**Settings → General → VPN & Device Management → your Apple ID → Trust**.
Open the BlazePod app from your home screen.

## After every code change

When I push a new version to GitHub:

```bash
cd ~/path/to/blazepod
git pull
npm run ios:open
```

Then in Xcode click ▶ again. Takes 10–20 seconds.

## Every 7 days

Apps signed with a free Apple ID expire after 7 days. To extend:

1. Plug iPhone into Mac
2. Open Xcode (the workspace is in `ios/App/App.xcworkspace` — Xcode remembers it)
3. Click ▶ Run

App reinstalls fresh, good for another 7 days.

If you want to skip that re-sign chore, $99/yr Apple Developer Program gives
1-year signing certificates; sign up at [developer.apple.com](https://developer.apple.com/).

## Architecture quick map (so the Mac-side commands make sense)

```
web/            ← source HTML/CSS/JS (mobile-first, also deployed to Vercel)
  js/pod.js       dispatcher: picks pod-cap.js on iOS, pod-web.js otherwise
  js/pod-cap.js   Capacitor BLE — uses CoreBluetooth via the plugin
  js/pod-web.js   Web Bluetooth — used in Chrome/Vercel preview
  js/protocol.js  shared auth CRC + codecs (port of src/blazepod/protocol.py)
vite.config.mjs ← Vite builds web/ → dist/ (Vite resolves bare imports)
capacitor.config.json ← points Capacitor at dist/
ios/            ← Xcode project (generated). Open ios/App/App.xcworkspace.
                  Don't edit by hand — it's regenerated by `npx cap sync`.
```

## Troubleshooting

- **"This app cannot be installed because its integrity could not be verified."**
  → Settings → General → VPN & Device Management → Trust your Apple ID profile.
- **No pods showing in the picker.** Same as Bluefy — wake the pods first by
  tapping each one. With CoreBluetooth they should appear within a few seconds.
- **Build fails with code-signing errors.** Make sure you picked your Apple ID
  in the Team dropdown (Signing & Capabilities). You may also need a unique
  Bundle ID — append your initials, e.g. `dk.snerls.blazepod.js`.
- **Pods immediately disconnect (~10 s).** That was the Web Bluetooth iOS
  problem. The native app uses CoreBluetooth and should not have it. If it
  does, file an issue with the device log from Xcode's console.
